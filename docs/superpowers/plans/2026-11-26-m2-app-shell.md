# Milestone 2: App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A buildable, sandboxed macOS app with:

- a three-column window (thread list, read-only transcript, inspector)
- the connection form and the demo
- Settings with saved Gateways
- local and CI build tooling and the ast-grep layer rules

**Architecture:** XcodeGen generates the app target from `project.yml`. The app target compiles `App/` directly and links the package's `OhMyOpenClawCore` product, as in the iOS repository. Pure Mac logic lives in `App/Platform/` and is exposed to `swift test` as the `OhMyOpenClawPlatform` target. Views stay thin over `AppModel`.

**Tech Stack:**

- SwiftUI on macOS 27 (`NavigationSplitView`, `.inspector`, `Settings`)
- XcodeGen 2.46
- Swift Testing for logic, XCTest for the UI smoke test
- ast-grep 0.51
- GitHub Actions `xcode-27`

**Spec:** [docs/superpowers/specs/2026-11-26-macos-client-design.md](../specs/2026-11-26-macos-client-design.md)

## Tasks

### Task 1: Platform target and thread list (TDD)

- [ ] Add `OhMyOpenClawPlatform` (`path: "App/Platform"`) and `OhMyOpenClawPlatformTests` to `Package.swift`. Exclude the app-only paths from `OhMyOpenClawState`, as iOS does.
- [ ] Write `ThreadListTests`:
  1. Main sessions come first and the remaining order is kept.
  2. A query filters titles case-insensitively.
  3. A whitespace query returns everything.

  Run `swift test --filter ThreadList` and expect a compile failure: no `ThreadList`.
- [ ] Implement `ThreadList.rows(_:matching:)`. Run `swift test` and expect a pass. Commit with `feat: add the sidebar thread list`.

### Task 2: Project, entitlements, and icon

- [ ] Write `project.yml`:
  - macOS 27 deployment target
  - product name "Oh My OpenClaw", module `OhMyOpenClaw`
  - bundle ID `run.kandot.oh-my-openclaw.mac`
  - generated Info.plist keys: display name, developer-tools category, local network usage text
  - entitlements path
  - automatic signing, defaulting to Sign to Run Locally (`CODE_SIGN_IDENTITY: "-"`)
- [ ] Write the entitlements file. Copy `App/AppIcon.icon` from oh-my-openclaw-ios@e9a5515 and add `macOS` to `supported-platforms.squares`.
- [ ] Add `*.xcodeproj/` to `.gitignore` (already present). Run `xcodegen generate` and expect the project to be created.

### Task 3: Scenes and views

- [ ] `OhMyOpenClawApp`: `Window("Oh My OpenClaw", id: "main")` with `RootView`, and `.task { await model.restore() }`. The `Settings` scene holds `SettingsView`. Closing the window keeps the app running; this is the SwiftUI default for `Window`.
- [ ] `RootView`:
  - Sidebar: `ThreadSidebar`.
  - Detail: `ConnectionView` when there are no sessions, otherwise `TranscriptView`.
  - `.inspector(isPresented:)` shows `ThreadInspector`. A toolbar button and Cmd-Option-I toggle it.
- [ ] `ThreadSidebar`:
  - `List(selection:)` over `ThreadList.rows`; selecting a row calls `model.selectSession`.
  - `.searchable(placement: .sidebar)`.
  - A footer shows the connection state, with reconnect.
- [ ] `TranscriptView`:
  - `ScrollView` with `LazyVStack`, anchored to the bottom.
  - User messages are trailing bubbles. Assistant messages use `MarkdownMessageView`.
  - "Load older" calls `loadOlderHistory`.
  - An error banner shows `errorMessage` or `notice`.
- [ ] `ConnectionView`:
  - The iOS onboarding fields in a macOS `Form`: alias, method picker, URL, token or password, setup code.
  - Connect, and "Try the demo".
  - Pairing guidance with the request ID and the `openclaw devices` commands.
- [ ] `SettingsView`:
  - Connection status, reconnect, and disconnect.
  - Saved Gateways: switch, rename, and delete with confirmation.
  - "Add Gateway" opens a sheet with `ConnectionView`.
  - The version comes from the bundle.
- [ ] Commit with `feat: add the app shell with connection, demo, and settings`.

### Task 4: Layer rules (ast-grep, test-first)

- [ ] Add `sgconfig.yml`.
- [ ] Add `rules/shared-layer-no-ui-frameworks.yml`, which bans SwiftUI, AppKit, and UIKit imports in `Sources/OhMyOpenClawCore/**` and the three shared `App/` files.
- [ ] Add `rules/no-uikit.yml`, which bans UIKit imports everywhere.
- [ ] Write `rule-tests/*` with valid and invalid snippets. Run `ast-grep test` before adding the rules and expect a failure, then a pass after. Run `ast-grep scan` and expect no findings.
- [ ] Commit with `chore: enforce layer rules with ast-grep`.
